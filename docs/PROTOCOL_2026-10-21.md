## Source/evidence

**From collaborator's TLS plaintext log** (NOT from the encrypted .5.pcapng):
- TLS v1.2, ALPN http/1.1; Switch 192.168.137.13 -> lab 192.168.137.1:11702.
- POST /c928398a5e4b4debb4099f62383eb196.svc/44829c126af14aeb9f535e504fa413ee
- Content-Type application/protobuf; Content-Length 806. Request total with headers 992 bytes.
- Same request reappeared on fresh connections about every 20 seconds. The original server.py logger **never replied**, so retries do not show rejection of any proposed payload.
- Decoded layout matches IEndpointDispatcherService_GetEnvironmentInfo:
  field 1 = AuthorizationClientData (BuildConfiguration=Retail, BuildVersion=0.1.DEV.8802288/PREBUILD),
  field 2 = repeated ServiceVersionRecord (19 records in displayed body).
- No server response body, response status, successful sign-in or next RPC is available in that log.

**From NSO main**:
- Both GUID strings occur in main.rodata (relative rodata offsets 0x49ef5f and 0x4e2a1c).
- Embedded descriptors define ServiceResult.retCode=1 (Success=0);
  ServiceResult.ServiceResult_EnvironmentList field **86868329**;
  ServiceResult_EnvironmentList.data=1; EnvironmentList.Environments=1.
- EnvironmentInfo contains Endpoint=1, EnvironmentId=2, Region=3,
  LocalizedDescription=4, DataCenters=5, IsUnderMaintenance=6;
  EnvironmentList.Date=2.
- CompactEndpointInfo contains Name=1, IP=2, Port=3, Protocol=4
  (Protocols_HTTPS=1), IsDefault=5.
- These are *wire-format facts*. The exact **accepted field values**
  and next-state requirements must be traced in ARM64 client code and
  checked with the actual Switch.

**From encrypted .5.pcapng** (different observation):
- 597 frames; remote TCP/TLS 11702 & 11704 sessions. TLS data encrypted.
- 108 UDP 38-byte UUID-shaped probes to 14 remote UDP/50000 targets,
  92 echoed replies from 13. Consistent with reachability/ping,
  **not evidence of actual gameplay packets**.

## Runnable experiment

The separate mvp_server.py serves test TLS and a *candidate* EnvironmentList
on the first proven GUID route. Start with:

    py gen_certs.ps1  # Incorrect: PowerShell scripts must be run IN PowerShell
    # In a PowerShell terminal:
    .\gen_certs.ps1
    py mvp_server.py --host 0.0.0.0 --capture-dir captures

Or locally without certificates:

    python mvp_server.py --no-tls --ports 11702
    python -m unittest discover -s tests -v

Test endpoints in routes.mvp.example.json are illustrative, not authoritative.
Unknown RPCs return 404; no authentication, lobby, gameplay server or relay exists.
Raw captures may contain authentication material. Never commit certs, raw logs
or token-bearing protobuf bodies to a public repo.
