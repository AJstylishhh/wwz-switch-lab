## Safe next step (on collaborator's test PC)

The existing \`mvp_server.py --capture-dir captures\` saves each incoming
request to a private \`.bin\` with a matching \`.json\` containing the
normalized RPC path. From the branch root:

\`\`\`powershell
py auth_probe.py captures
\`\`\`

This picks the most recent matching 11704 request and prints **only field
numbers, wire types, byte lengths and ranked method names**. It prints
no raw strings, login passwords, session tokens or fingerprints.
Share its JSON output, **not** the original private \`.bin\` payload
or TLS private key.

For more accurate method identification, dynamic parsing and ARM64
cross-references should still be used. Optional protobuf fields can make
multiple candidates look compatible.
